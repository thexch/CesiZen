# Frontend CESIZen

Interface React du projet CESIZen.

## Lancer le frontend en développement

```bash
npm install
npm run dev
```

Le site tourne sur `http://localhost:5173`.

## Tester la PWA

```bash
npm run build
npm run preview
```

La version PWA se teste ensuite sur `http://127.0.0.1:4173`.
